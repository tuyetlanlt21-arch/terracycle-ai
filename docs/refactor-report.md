# TerraCycle AI refactor report

## Deleted

Removed NASA GPM IMERG and GLDAS adapters, cached datasets, integration outputs, salt-risk engine, salt-specific tests, demo request fixture and obsolete audit report.

## Modified

NASA POWER, FastAPI models/routes/service, React/Vite client, documentation and dependency manifest.

## Added

`datascience/soilgrids.py`, `datascience/ecocrop.py`, `data/reference/crop_catalog.json`, `data/reference/rotation_rules.json`, `docs/data-sources.md` and new validation tests.

## Data status

The repository preserves the existing verified NASA POWER daily CSV and metadata. New target outputs are generated by the POWER pipeline when the NASA endpoint is reachable. SoilGrids and ECOCROP adapters are implemented but no successful new downloads were claimed: SoilGrids availability is external/runtime-dependent and no verified ECOCROP export was present.

## Validation

- Python and backend tests: 4 passed.
- Python compileall: passed.
- Frontend TypeScript and Vite production build: passed.
- No obsolete IMERG, GLDAS, salt-risk or salt endpoint references remain in source/docs.

## Limitations

The crop catalog is intentionally empty until traceable ECOCROP records are supplied. Rotation scoring is an explainable MVP heuristic, not a yield, profit, salinity or forecast model. Farmer soil salinity EC and irrigation-water EC remain unknown unless supplied by the farmer/local source.
